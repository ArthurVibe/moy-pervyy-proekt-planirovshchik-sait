# What’s Up, Bro? — The Private Club

Самостоятельная интерактивная витрина UI-компонентов в стиле Private Club.

## Запуск

Откройте `index.html` в современном браузере. Установка, сборка, сервер и интернет не требуются: CSS, JavaScript, WebP и SVG встроены в HTML.

## Возможности

- Кнопки, поля, клиентская демоформа и переключатели.
- Карточки, галерея и доступные модальные окна.
- Ползунки, демонстрационный прогресс и индикатор готовности страницы.
- Вкладки, аккордеон, подсказки, бейджи и копирование дизайн-токенов.
- Адаптивность, клавиатурное управление и reduced motion.

Формы не отправляют данные; авторизация, backend, календарь и AI не реализованы. Настройки и пароли не сохраняются. Концепт Bro показан как визуальный референс; остальные визуалы помечены как демо-ассеты.

## GitHub Pages

В Settings → Pages выберите **Deploy from a branch**, ветку **main** и каталог **/ (root)**. Наличие файла `.nojekyll` отключает обработку Jekyll.

Ожидаемый адрес после успешного развёртывания:
https://arthurvibe.github.io/moy-pervyy-proekt-planirovshchik-sait/

Адрес выше не подтверждает, что Pages уже включён. Состояние публикации проверяется в настройках репозитория и по ответу сайта.
