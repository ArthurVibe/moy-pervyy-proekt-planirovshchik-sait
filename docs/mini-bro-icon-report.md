## Реализация

Mini Bro — статичный декоративный `<picture>` внутри Hero: WebP с PNG fallback, `srcset` для обычных и Retina-экранов. Семь файлов из пользовательского ZIP скопированы побайтно; размеры и SHA-256 приведены в [assets/mini-bro/README.md](../assets/mini-bro/README.md). Прозрачность, лицо, пропорции, цвета и исходный бронзовый контур сохранены.

Размер составляет 64 × 64 CSS px на desktop и 48 × 48 CSS px при ширине до 767 px. Элемент абсолютно позиционирован относительно Hero и прокручивается вместе с ним. На mobile Hero немного выше первого viewport; ограничение через `100svh` удерживает иконку полностью в первом экране. При этом элемент не становится фиксированным относительно документа.

| Viewport | Координаты верхнего левого угла | Отступ справа / снизу viewport |
|---|---|---|
| 1440 × 900 | 1352, 812 | 24 / 24 px |
| 1280 × 800 | 1192, 712 | 24 / 24 px |
| 390 × 844 | 326, 780 | 16 / 16 px |

Нет карточки, подписи, дополнительной рамки, обработчиков, фокуса или анимаций иконки. `aria-hidden`, пустой `alt` и `pointer-events: none` исключают ложное впечатление доступного управления. Существующие кнопки, уведомление Coming soon и анимации Hero сохранены.

## Проверки

- Локальный Chromium 154.0.8037.57: все три viewport, загрузка изображений и шрифта, отсутствие перекрытия элементов управления и горизонтальной прокрутки.
- Сравнение геометрии 19 существующих элементов с базой: без изменений. После удаления только новых CSS и `<picture>` HTML побайтно совпадает с утверждённой версией; исходный JavaScript не изменён.
- [Пиксельное сравнение](previews/mini-bro-v1/pixel-comparison.json): во всех трёх размерах **0 изменённых пикселей вне прямоугольника иконки**.
- Retina DPR 2: браузер выбирает WebP 128 px на desktop и mobile; PNG fallback также выбирает 128 px. Иконка остаётся статичной во время существующей hover-анимации Meet Bro.
- Визуально проверены лицо большого Bro, заголовок, кнопки и нижняя правая область: иконка их не перекрывает.
- [Проверка публичной HTTPS-страницы в Chrome через GitHub Actions](https://github.com/ArthurVibe/private-club-hero-preview/actions/runs/40007494233) завершилась успешно: те же viewport, геометрия, Retina, fallback, меню и Coming soon. TLS-проверка не отключалась.
- Дополнительно выполнены 16 HTTP-проверок: тестовый HTML, все семь иконок, исходная фотография PNG/WebP и шрифт загружаются с кодом 200 и совпадают с локальными файлами по SHA-256; прежние публичные страницы также совпадают с сохранёнными контрольными суммами.

[Локальный отчёт проверки](previews/mini-bro-v1/verification.json). Проверки выполнены в браузерах Linux; физические iPhone/Android и Safari в эту проверку не входили.

Для воспроизведения локально запустите `python3 -m http.server 8792 --bind 127.0.0.1` из корня репозитория и откройте `http://127.0.0.1:8792/`. Автоматические проверки: `node docs/qa/verify-mini-bro.cjs` при доступном Playwright/Chromium, затем `python3 docs/qa/compare-mini-bro.py` при доступном Pillow. Путь к установленному Playwright и Chromium можно передать через `PRIVATE_CLUB_PLAYWRIGHT_MODULE` и `PRIVATE_CLUB_CHROMIUM_EXECUTABLE`.
