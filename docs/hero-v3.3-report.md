## Почему понадобился JavaScript

В отдельной проверке Chromium воспроизведено ограничение CSS: правило вида `.brand:is(:hover, :focus-visible)` запускает волну при получении фокуса, но следующий hover при сохранённом фокусе не меняет совпадение селектора. Счётчик animationstart остаётся равным 1 вместо нового прохода. Также чистый CSS hover не различает касание и мышь на гибридном устройстве.

Минимальный контроллер хранит признаки реального pointer-hover и источника волны. При новом входе он снимает атрибут волны, подтверждает сброс вычисленного CSS-состояния и вновь включает одну CSS-анимацию. Уход отменяет незавершённый hover-проход. Фокус логотипа и hover объединяются без наложения; blur не отменяет активную hover-волну. Для touch учитывается `pointerType` и pointerId, состояние снимается на pointerup/pointercancel. Таймеров, циклов requestAnimationFrame и покадровой JS-анимации в этом контроллере нет. Существующий код Coming soon, меню и Warm Welcome сохранён.

Метод: в отдельном QA-прогоне CSS-анимации и переходы приостановлены в заданные моменты. Надпись временно делается прозрачной для захвата фактического фона во всём прямоугольнике текстового range; фон включает градиент, волну, прозрачность и фотографию. Непрозрачный цвет текста отрисовывается отдельной 8×8 пробой через тот же вычисленный brightness-фильтр и считывается из PNG. Таким образом учитывается изменение и фона, и текста; цвета сглаженных краёв глифов не используются. Для каждого фонового пикселя вычисляется отношение относительных яркостей sRGB по WCAG 2.x, берётся минимум. После снимка проба и временный стиль удаляются; в интерфейсе их нет.

Значения ограничены выбранными кадрами, viewport и Chromium. Дополнительно границы гарантирует сохранённая светлая область градиента под текстом: hover осветляет её, бронзовая волна также светлее; touch меняет только кромку и тень. ## Воспроизведение

Локальный просмотр без публикации:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8000/`; сравнение Warm Welcome — `http://127.0.0.1:8000/?warmWelcome=off`. На Windows можно использовать `py -m http.server ...`. Страница автономна, ресурсы локальные.

QA запускается отдельно, из корня репозитория, при наличии Node, Playwright, Chromium, Python с Pillow и ffmpeg. Это инструменты проверки, не зависимости сайта. `PRIVATE_CLUB_PLAYWRIGHT_MODULE` задаёт путь к установленному Playwright, `PRIVATE_CLUB_CHROMIUM_EXECUTABLE` — к Chromium, `PRIVATE_CLUB_PREVIEW_URL` — адрес локального сервера (по умолчанию порт 8768):

```sh
node docs/qa/verify-v3.3.cjs
node docs/qa/additional-v3.3.cjs
node docs/qa/contrast-v3.3.cjs
python3 docs/qa/measure-v3.3.py
node docs/qa/capture-v3.3.cjs
```
