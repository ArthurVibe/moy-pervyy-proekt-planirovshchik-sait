# Stage 1 — Private Club v2.0

Дата: 21.10.2026. Статичная реализация подготовлена для визуального согласования; к этапу анимаций не переходили.

Ветка: `feature/private-club-hero`. Исходники и скриншоты сохраняются в feature-ветке GitHub для визуального согласования. Слияние и публикация сайта не выполнялись. `main`, резервная метка `before-private-club` и исходный коммит ветки остаются на a35c0f3. Репозиторий планировщика не затрагивался.

## Выполнено

- Существующая UI-витрина заменена в feature-ветке только на Header + Hero.
- Утверждённый текст, типографический двухстрочный логотип, подпись, меню и настоящие HTML-кнопки.

- На mobile текст над фотографией — разрешённый спецификацией вариант, без генерации отдельной сцены.
- Мобильное меню: клавиатура, Escape, повторное нажатие, выбор пункта, закрытие снаружи и сброс при смене ширины.
- Coming soon появляется только после действия, без регистрации и сдвига компоновки.
- Анимаций, transitions, бликов и Warm Welcome нет.

## Ограничения

- Отдельного SVG/PNG логотипа не предоставлено; используется разрешённая ТЗ HTML/CSS-версия на локальном Playfair Display, системный sans-serif для интерфейса. Playfair Display загружен из официального Google Fonts; лицензия SIL OFL включена в assets/fonts/OFL.txt.
- Safari/macOS, Safari/iOS, Firefox, Edge и реальные телефоны не проверялись; мобильные размеры эмулированы в Chromium.
- Полный аудит WCAG не выполнялся; проверены видимый фокус, корректные ID/ARIA, клавиатурные сценарии и отсутствие обрезания контента.
- Прямое file:// ограничено политикой управляемого Chromium; проверка выполнена через локальный HTTP. Относительные ассеты и обычный script не требуют backend.

Публиковать страницу и переходить к анимациям только после отдельного согласования.

## Уточнение по последнему запросу
