# Page 02 v2.0 — карусель JUST TELL BRO.

Дата: 24 октября 2026 года. Ветка: [`feature/private-club-page-2-carousel`](https://github.com/ArthurVibe/moy-pervyy-proekt-planirovshchik-sait/tree/feature/private-club-page-2-carousel), создана строго от `0ed62f88d53e32d25a628ec8b94b69f05b5a7a91`.

После Hero добавлена секция `#how-it-works`: одна общая HTML-шапка с утверждёнными четырьмя строками, Playfair Display, ivory и акценты aged bronze. Размытый клубный WebP и тёмный градиент используются только в этой секции. Ни один графический элемент не накладывается поверх иллюстраций.

Все пять WebP из `web/` пользовательского архива скопированы побайтно в `assets/page-02/`; [контрольные суммы и размеры](../assets/page-02/manifest.json) совпадают с архивом. Слайды идут в порядке 01–04, имеют `loading="lazy"` и исходные размеры. `object-fit: contain` сохраняет полное изображение; немного отличающаяся пропорция четвёртой иллюстрации компенсируется свободным пространством, без обрезки. Встроенный в картинки текст уменьшается вместе с ними на телефоне; под каруселью сохранено читаемое пояснение из прототипа.

Стрелки, четыре точки и счётчик работают без автоперелистывания. На границах 01/04 соответствующая стрелка обозначается недоступной; карусель не зациклена. Свайпы реализованы нативной горизонтальной прокруткой со scroll snap. С клавиатуры доступны Left/Right, Home/End и Tab/Enter. Есть заметный фокус, подписи изображений, один текущий слайд для accessibility tree и одно спокойное live-объявление после переключения. Reduced motion отключает плавную прокрутку, в том числе при изменении настройки во время движения.

Оба How It Works стали настоящими ссылками на секцию с сохранёнными классами, размерами и hover-эффектами. Переход закрывает мобильное меню и переносит фокус в секцию. Без JavaScript ссылки остаются рабочими, картинки можно прокручивать нативно, неработающие кнопки управления скрыты. Hero и новая секция помещены в общий `main`; геометрия Hero сохранена. Старый JavaScript меню, Coming soon, Warm Welcome и кнопок побайтно не изменён.

## Проверки

- Chromium 154.0.8037.57: все четыре изображения, стрелки в обе стороны, точки, клавиатура, фокус, границы 01/04, отсутствие автопрокрутки и горизонтальной прокрутки документа проверены во всех четырёх viewport. Общая шапка не дублируется и не меняется при переключении.
- На телефоне проверены настоящие touchStart/touchMove/touchEnd через CDP: два свайпа влево и один вправо; программная установка `scrollLeft` для этого теста не использовалась.
- Проверены reduced motion до и во время переключения, resize с сохранением выбранного слайда, прямой вход по `#how-it-works`, быстрые повторные нажатия Next, переходы из Hero и мобильного меню, Enter на ссылках, сохранность Coming soon и hover-эффектов Hero.
- Все изображения загружаются, исходные пропорции сохранены, лицо, тексты и интерфейсные карточки остаются в кадре. Новых ошибок JavaScript и ошибок загрузки ресурсов в проверенных сценариях нет.
- Весь viewport Hero совпал с исходной версией: **0 изменённых пикселей** при 1440 × 900, 1280 × 800, 1024 × 768 и 390 × 844; сравнение выполнено после загрузки шрифта и завершения прежнего проявления текста, без hover. Геометрия 18 существующих элементов также совпадает.

Отчёты: [интерактивные проверки](previews/page-02-v2.0/verification.json), [снимки и Enter-навигация](previews/page-02-v2.0/capture-verification.json), [пиксельное сравнение Hero](previews/page-02-v2.0/hero-pixel-comparison.json). WebKit/Safari и физические телефоны не проверялись; touch и адаптивность проверены в Chromium.

## Локальный просмотр

В локальной копии указанной ветки запустите из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/` и нажмите How It Works либо сразу откройте `http://127.0.0.1:8000/#how-it-works`. Сборка и установка зависимостей для страницы не нужны.

Для воспроизведения QA нужен Playwright/Chromium и Python/Pillow. При локальном сервере на 8797 запустите `node docs/qa/verify-page-02.cjs`, `python3 docs/qa/compare-page-02.py`, затем `node docs/qa/capture-page-02.cjs`. При необходимости задайте `PRIVATE_CLUB_PLAYWRIGHT_MODULE` и `PRIVATE_CLUB_CHROMIUM_EXECUTABLE`; другой адрес сервера — через `PRIVATE_CLUB_PREVIEW_URL`.

Изменён `index.html`; добавлены `assets/page-02/`, три сценария `docs/qa/*page-02*`, этот отчёт, 16 PNG и три JSON в `docs/previews/page-02-v2.0/`. Использованы только изображения из архива; у страницы нет новых библиотечных зависимостей.

`main`, прежние ветки и теги сохранены. Опубликованные сайты и предпросмотры не изменялись, новая публикация и merge не выполнялись. Работа остановлена для визуального согласования.
