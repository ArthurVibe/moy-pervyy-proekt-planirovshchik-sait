# Этап 2 — анимации THE PRIVATE CLUB

Дата: 22.10.2026. Базовая версия: bffb72c9e968b81a941399d9e1a7f0d2ea5764f6 / private-club-hero-v1.0. Ветка: feature/private-club-hero.

## Изменения

Добавлены только эффекты, описание запуска и материалы для просмотра. Базовые размеры, отступы, положение текста/кнопок, фотографии, лицевая область, шрифты и мобильная композиция не менялись. Статичные скриншоты предыдущего этапа сохранены. Новых секций, форм и библиотек анимации нет.

Основная реализация — CSS transitions/keyframes и псевдоэлементы. JavaScript рассчитывает положение и безопасную ширину Warm Welcome, читает URL-параметр, учитывает тип указателя и системный reduced motion, а также фиксирует однократное окончание intro. Постоянных requestAnimationFrame-циклов и интервалов нет. ResizeObserver реагирует только на изменение размеров.

Световой слой имеет pointer-events:none, находится между фотографией и текстом, заканчивается за 24px до консервативной границы фигуры и дополнительно затухает на последних 120px. Его ширина ограничена шириной Hero даже во время изменения окна.

## Дополнительные доказательства

- Bounding rectangles, семейства, веса и размеры шрифтов для 15 элементов совпали с HTML утверждённого тега при 1440×900 и 390×844.
- Пиксельное сравнение скриншотов Warm Welcome on/off: правая область x=840…1440 полностью совпадает; изменение присутствует только слева.
- Hover-сценарии на постоянной ширине не вызвали layout shifts (сумма 0).
- RGB-изображения и исходные файлы PNG/WebP сохранены; SHA-256 PNG: 0a2cc60f3e48bd23b9506003be29b94e028df8b5f2d1febd2ba870ae7c34590d.
- JS-ошибок и внешних запросов в проверенных сценариях нет.
- Длительность MP4 13,75 с; H.264 1440×900, 24 fps. GIF 960×600, 12 fps. Запись выполнена в Chromium через CDP, закодирована ffmpeg.

## Ограничения и локальный просмотр

Safari, Firefox, Edge, реальные телефоны и аппаратная производительность на слабых устройствах не проверены. Выполнена проверка отсутствия постоянных JS-циклов и layout shifts; это не полный аппаратный benchmark или аудит WCAG. GIF использует ограниченную палитру и служит только демонстрацией.

Для интерактивного просмотра выполните инструкции README на собственном компьютере. Параметр ?warmWelcome=off отключает только свет; блики и другие hover-эффекты продолжают работать. Системный reduced motion отключает всё декоративное движение, включая intro.
